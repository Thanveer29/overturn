# Overturn frontend

React + TypeScript + Vite. See [`../docs/architecture/frontend.md`](../docs/architecture/frontend.md)
for the design, component notes, and live verification writeup.

```bash
npm install
npm run dev      # http://localhost:5173, expects the backend on :8000 (see ../docs/architecture/frontend.md)
npm run lint
npm run build
```
